College ERP System

A College Enterprise Resource Planning (ERP) System developed using Core Python and SQLite to manage student and teacher information through a simple login-based interface.

📌 Project Overview

The College ERP System is a Python-based application designed to organize college records and provide separate access for administrators, students, and teachers.

✨ Features

- Login System: Provides a login interface for accessing the application.
- Admin Module: Supports administrative operations.
- Student Management: Organizes student information.
- Teacher Management: Organizes teacher information.
- Database Management: Uses SQLite to store and retrieve records.
- Modular Code: Separates functionality into different Python files.

🛠️ Technologies Used

- Python
- SQLite
- SQL
- Git and GitHub

⚙️ Requirements

- Python 3 installed on your computer
- A code editor such as Visual Studio Code

SQLite support is included with standard Python installations.

▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Check that the database is initialized correctly.
4. Run the main application:

python main.py

5. Follow the on-screen instructions to use the application.

🎯 Project Objective

The objective of this project is to practice Python programming, database connectivity, SQL operations, and modular application development through a practical college management application.
